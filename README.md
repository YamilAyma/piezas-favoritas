### 📝 Guía rápida: Cómo guardar links limpios
Para mantener la estética del repositorio y evitar el rastreo de YouTube, sigue estos pasos:

1. **Obtener el link:** Clic en **Compartir** en YouTube y **Copiar**.
2. **Sanitizar:** Borra todo lo que aparezca después del código del video (borra desde el `?si=...`).
   * *Ejemplo sucio:* `https://youtu.be/osg_WmeLxQk?si=CZ66CxHzIXv5-`
   * *Ejemplo limpio:* `https://youtu.be/osg_WmeLxQk`
3. **Añadir tiempo:** Agrega `?t=` seguido del minuto y segundo.
   * *Formato:* `?t=1m45s`
   * *Resultado final:* `https://youtu.be/osg_WmeLxQk?t=1m45s`

**Estructura final recomendada:**
`[01:45 - Ver momento](https://youtu.be/CÓDIGO?t=1m45s)`
